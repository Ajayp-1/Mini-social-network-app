# 📱 Mini Social Network App

## 📌 Overview
A mini social networking platform that allows users to create profiles, connect with others, share posts, and interact through likes/comments.

## 🚀 Features
- User authentication (login/signup)
- Create and manage profiles
- Post creation and feed
- Like and comment system
- Data storage and retrieval

## 🧠 Data Science / Logic (if applicable)
- User activity analysis
- Recommendation logic (basic)
- Data handling and processing

## 🛠️ Tech Stack
- Frontend: (React / HTML / CSS)
- Backend: (Node.js / Flask / Django)
- Database: (MySQL / MongoDB)
- Language: Python / JavaScript
